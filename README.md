# Personal Finance Tracker - Backend

## Project Overview

Personal Finance Tracker is a Java Full Stack application that helps users manage their personal finances by tracking income, expenses, budgets, and financial reports.

This repository contains the Spring Boot backend application that exposes REST APIs for the Angular frontend.

---

## Technologies Used

- Java 21
- Spring Boot 3
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST APIs
- Git & GitHub

---

## Features

- User Registration
- User Login
- Dashboard Summary
- Transaction Management
- Budget Management
- Financial Reports
- REST API Integration
